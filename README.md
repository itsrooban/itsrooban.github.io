# Thathrooban Nedunchezhiyan — interactive portfolio

Responsive portfolio with an animated robotics motion study, interactive exploded assemblies, and an adjustable payload load-distribution illustration. It uses local files only and needs no build step or external libraries.

## Preview
Open index.html in a modern browser. To view it on a phone, upload this folder to a web host or GitHub Pages and open its URL.

## Publish with GitHub Pages
1. Create a GitHub repository and upload the contents of this folder to its root.
2. Open Settings → Pages.
3. Choose Deploy from a branch, select main and /(root), then save.
4. Share the URL GitHub Pages provides.

The share buttons use the phone's native share menu when hosted over HTTPS, or copy the public URL. Contact links and the downloadable resume are public to site visitors.
