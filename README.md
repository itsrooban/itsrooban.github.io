# Thathrooban Nedunchezhiyan — interactive mechanical engineering portfolio

A responsive portfolio site with an offline, code-built 3D-style workbench for a robot arm, a generic plasma process tool and an AMR base. It also includes exploded assembly drawings and a live payload load-distribution illustration. The site uses local files only: no API key, remote images or external libraries are required.

## Explore the workbench

- Choose a machine with the three model tabs.
- Drag the model, or drag with one finger on a phone, to orbit the view.
- Scroll or pinch over the model to zoom.
- Use Assembly separation to move modules apart.
- Adjust the motion-phase slider or play/pause the cycle.
- Select an inspection-focus chip to highlight a component, or reset the view.

The 3D-style models are illustrative portfolio visualizations. They are not production CAD, proprietary Applied Materials or BGR machine models, certified analysis, or equipment specifications. The structural calculator is a simplified two-support beam model; its assumptions are described on the page.

## Preview

Open index.html in a modern browser. Keep engineering-viewer.css, engineering-viewer.js and resume.docx in the same folder as index.html. The layout adapts for laptops and phones.

## Publish with GitHub Pages

Upload every file in this folder to the root of your GitHub Pages repository, including index.html, engineering-viewer.css, engineering-viewer.js, resume.docx and this README. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the main branch and /(root), then save. The share buttons use a phone's native share menu when hosted over HTTPS, or copy the public URL.
